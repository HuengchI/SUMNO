Following the Code Availability statement of the paper, this repository will provide:

- Complete training and evaluation code for SUMNO and all baselines (including our adaptations)
- Data preprocessing scripts
- Configuration files
- Trained model checkpoints, so that the reported results can be obtained by running the evaluation directly, without retraining
