# SUMNO

**SUMNO: Spatially Unrolled Multigrid Neural Operator for Fluid Flow Surrogates**

Official repository for the paper above.

> **Status: coming soon.**
> The paper is currently under review. The code will be released here once the paper is accepted.

## Paper

- arXiv: [arXiv:2611.16341v1](https://arxiv.org/abs/2611.16341)
- Journal: *under review*

## Planned release

Following the Code Availability statement of the paper, this repository will provide:

- Complete training and evaluation code for SUMNO and all baselines (including our adaptations)
- Data preprocessing scripts
- Configuration files
- Trained model checkpoints, so that the reported results can be obtained by running the evaluation directly, without retraining
